# Thinking Machines: a short history of AI

A 9-minute narrated video on how artificial intelligence developed, from Turing's 1950 question to today's reasoning models and agents.

- **Video:** [`ai-history.mp4`](ai-history.mp4) (1920×1080, 30 fps, with narration and music)
- **Subtitles:** [`ai-history.srt`](ai-history.srt)
- **Script:** [`script.json`](script.json). Narration, on-screen titles and facts all come from this file.

## How it's made

Everything is generated by code. There's no stock footage and no image models.

| Step | File | What it does |
| --- | --- | --- |
| Narration | `tts.py` | Speaks each sentence with [Piper](https://github.com/rhasspy/piper) TTS, using the `en_US-ljspeech-high` voice (public-domain LJSpeech dataset). It then lays out the timeline: scene and sentence timings go in `build/timeline.json` and subtitles in `ai-history.srt`. |
| Music | `music.py` | Synthesizes an ambient score with numpy. It turns cold and sparse during the two AI winters and gets busier in later eras. |
| Visuals | `render.mjs`, `scenes.mjs`, `lib.mjs` | Draws every frame on a canvas ([`@napi-rs/canvas`](https://github.com/Brooooooklyn/canvas)) and pipes the frames to ffmpeg. Each frame depends only on its timestamp, so frame ranges render in parallel. |
| Assembly | `build.sh` | Renders in parallel and joins the parts. It then mixes the narration over the music, lowering the music while someone is speaking, and normalizes loudness to −16 LUFS. |

### Rebuild

Requirements: Node 18+, ffmpeg, and Python 3 with `piper-tts` and `numpy`.

```sh
npm install
pip install piper-tts numpy
curl -LO https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/ljspeech/high/en_US-ljspeech-high.onnx
curl -LO https://huggingface.co/rhasspy/piper-voices/resolve/main/en/en_US/ljspeech/high/en_US-ljspeech-high.onnx.json
VOICE=en_US-ljspeech-high.onnx ./build.sh
```

To change the story, edit `script.json` and rebuild. `tts.py` caches clips, so it only re-synthesizes sentences whose text changed. To check the layout without rendering the whole video, render a few still frames:

```sh
node render.mjs --stills 20,95,300 --dir build/stills
```

## Notes on accuracy

- Dates and figures follow widely cited sources: the original papers, ImageNet challenge results, and Nobel Prize announcements. The ImageNet chart shows the winning top-5 error for each year.
- The funding curve in the first-winter scene is labeled *illustrative*. It shows a trend and is not a dataset. The expert-system rules are invented examples in XCON's style.
- ChatGPT's user numbers are the widely reported estimates: 1 million users in 5 days and about 100 million in about two months.
